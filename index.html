The Problem

Clinic Queues Are Broken

In most clinics, patients wait in silence — nobody knows whose turn it is. Staff shout names, nurses walk the hallway, monitors show nothing. CareCall fixes this with zero complexity.

😤

Patients Miss Their Turn

No display means patients wander, miss their call, and block the queue — causing frustration for everyone.

📢

Staff Have to Shout

Nurses calling numbers by voice is unreliable, undignified, and doesn't scale to large waiting areas.

🏗️

Existing Systems Are Too Heavy

Commercial queue systems require dedicated hardware, complex software, and expensive licenses. CareCall needs nothing but a laptop and a TV.

The Solution

How CareCall Works

A doctor taps a token number. Every paired display screen shows and announces it instantly. No database. No login. No wires beyond the LAN.

1

🚀 Start the Server

Run npm start on any laptop. The server starts on your LAN in seconds. No cloud, no setup wizard.

2

📺 Open the Display on the TV

Open the TV browser, type the server's LAN IP. The Waiting Display loads — full-screen, bilingual, ready.

3

🩺 Doctor Opens Their Keypad

Doctor opens /dr/ on their desktop or /mobile/ on their phone. A clean Telugu keypad appears.

4

📡 Call the Token

Doctor dials the token number and taps Send. The WebSocket pushes the call to the display in <50 ms.

5

🔊 Display Announces It

The TV displays the number and speaks it in Telugu — "నంబర్ ఏడు". Elapsed time starts counting.

6

🔁 Repeat All Day

The doctor dials the next token. The display updates immediately. No page refresh, no server restart.

Quick Decision Guide

Use CareCall (V1) if…

  • You have one consultation room
  • All TVs should show the same call
  • You want zero configuration
  • You have a single doctor calling

Use CareCall Screens (V4) if…

  • You have 2+ consultation rooms
  • Each room has its own TV display
  • Doctors work independently
  • You run OPD with multiple doctors
Architecture

The One Key Difference

Same Node.js stack. The difference is in how the server routes a call event.

CareCall — Single Broadcast
Doctor ──call: 7──▶ /ws │ broadcast(wss, state) sends to ALL wss.clients │ ┌────────────┼──────────┐ Display 1 Display 2 Mobile (TV hall) (corridor) (tablet) all show 7, all speak
CareCall Screens — Key-Targeted
Doctor A (key:101) ──call: 7──▶ /ws?key=101 │ broadcastToKey("101", state) │ Display (key:101) → shows 7, speaks ✅ Doctor B (key:102) ──call: 3──▶ /ws?key=102 │ broadcastToKey("102", state) │ Display (key:102) → shows 3, speaks ✅ Display (key:101) untouched 🔇
The Screens

Three Beautiful UI Screens

Every screen is a standalone HTML file — no framework, no build step. Open in any modern browser.

📺

Waiting Display

Full-screen TV layout. Left panel shows the giant token number. Right panel shows elapsed time, room key, and department. Telugu audio announces each call. Voice toggle ensures browser autoplay compliance.

/display/
📱

Doctor Mobile

Compact touch keypad for smartphones and tablets. Shows a Live TV Mirror card ("NOW SERVING") reflecting what the display currently shows. Recall button re-broadcasts without re-dialling. Bottom nav for quick switching.

/mobile/
🩺

Doctor Console

Desktop workstation dialer. Full 0–9 keypad with +1 Quick Next button. Shows server connection status and (in V4) the count of paired display screens online. Telugu UI throughout.

/dr/
Voice Announcements

Bilingual Audio System

CareCall speaks to your patients in their language — Telugu first, English as fallback.

🔊 Telugu Audio Clips

Pre-recorded .wav clips for numbers 1–10 say "నంబర్ [word]" (e.g. "నంబర్ ఏడు" for 7). .mp3 clips cover numbers 11 through 30+. Served locally from public/audio/te/ — no internet required.

🗣️ English Web Speech

For numbers beyond the Telugu clip range, the browser's built-in speechSynthesis API announces in English. No extra files or APIs needed. Click anywhere on the Display screen to satisfy the browser's autoplay policy.

Quick Start

Running in Under a Minute

Node.js 20.6+ required. No other prerequisites.

📡 CareCall — Single Broadcast
# Clone or download the repo
cd appointment-notifier
npm install
npm start
# → listening on http://0.0.0.0:3001

# Doctor opens
http://localhost:3001/dr/

# TV opens
http://<LAN-IP>:3001/display/
🔑 CareCall Screens — Multi-Room
# Clone or download the repo
cd appointment-notifier-screens
npm install
npm start
# → listening on http://0.0.0.0:3002

# Doctor sets Room Key (e.g. 101)
http://localhost:3002/dr/  → enter key: 101

# TV sets same Room Key
http://<LAN-IP>:3002/display/  → enter key: 101

💡 Both servers can run on the same machine simultaneously — they use different ports.
